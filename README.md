# OPA Policy Enforcement Example

This Go program demonstrates how to use the Open Policy Agent (OPA) to enforce access control policies. It defines a simple Rego policy and evaluates several user requests against it, showing whether access is allowed based on the policy rules.

## Language

`go`

## How to Run

1. Ensure you have Go installed.
2. Run `go mod init example.com/opa-demo` in an empty directory.
3. Save the code as `main.go` in that directory.
4. Run `go run main.go`.
